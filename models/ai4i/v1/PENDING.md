# Pending AE-08 Artefacts

The following artefacts are generated by `python -m ml.aegis_ml.train` after the UCI dataset is acquired and Python ML dependencies are installed:

- `feature-schema.json`
- `thresholds.json`
- `metadata.json`
- `metrics.json`
- `model.onnx`
- `parity-report.json`
- `xgboost-model.json`

No scores or model artefacts are committed until the pipeline has run successfully in an environment with Python, XGBoost, ONNX conversion, and ONNX Runtime available. Threshold output must use the AEGIS Low/Medium/High T1/T2 contract.
